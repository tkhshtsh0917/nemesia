Nemesia Rust API

Reference for the Nemesia release running in this demo.

  • nemesia_engine: query a validated completion index.
  • nemesia_index: candidate types, normalization, and index reader.
  • nemesia_builder: compile an index from candidate rows.
  • nemesia_analyzer: extract Japanese candidates and ranking statistics on the server.
  • nemesia_wasm: the read-only WebAssembly boundary.
