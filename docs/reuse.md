Preserve required notices and put project provenance in README acknowledgments. Use the code's existing terms where applicable.

Nemesia should build and test from its own checkout. The demo consumes an explicitly selected Nemesia release, or an explicitly supplied CI/test artifact. The initial design adds no sibling-checkout dependency or Asearch runtime dependency. If extraction code later warrants a shared crate, first show matching semantics and maintenance benefit in both callers.
